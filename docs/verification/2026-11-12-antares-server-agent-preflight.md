12 ноября 2026 года на Windows Server 2012 R2 Datacenter (9600) установлен
корпоративный CA Sosnadmin с SHA-256
`5525eccf01536b7f0436d96500c663f7a58edac463f00f0fb34a59dd8b3250be`.
Windows проверила подписанный Setup 3.2.193 с меткой времени и ожидаемым
издателем. Основной и резервный входы Endpoint вернули HTTPS 200 после
добавления точного адреса 192.168.100.4 в резервный вход.

Подписанный Setup с SHA-256
`c1ea3b78634855426376cf2fe5bbe2b6cebb25826ae8e2cc8b307c3e73f08290`
завершил read-only preflight с кодом 0. Свободного места достаточно.
До установки Core и Foundation отсутствовали, конфликтов и незавершённых
транзакций не обнаружено. Нативный Setup затем завершился с кодом 21 на
этапе MSI до регистрации. PowerShell 4.0 на ANTARES возвращает
`MethodNotFound` для `::new()` из штатной оболочки MSI.

Кампания `f8e17c03-b9a9-49d1-83fe-75d4c477bf95` ограничена
192.168.100.4/32, Setup 3.2.193, ручным одобрением и одним использованием.
Заявки и устройства в production отсутствуют. Службы SMB и Kaspersky
Security Center сохранили PID.

Профиль `kaspersky_file_server` собран в Core 3.2.198 из коммита
`4701f78ddf53ad24e977f13e0c246034774136f3`. ZIP
`EndpointCore-3.2.198-4701f78d.zip` содержит 22 694 747 байт, SHA-256
`b8d69d8420b9f66d0b3628a5bc33e2cfbbe57a6ecc9a1fed40a6651ab777d8aa`.
Временный локальный запуск профиля на ANTARES подтвердил TCP 445 и 13000,
SMB-ресурсы и работающие службы KSC. AVP остановлена, C: занят на 32,3%,
E: на 84,4%. Console и API поддерживают новый профиль. Отчёт от
зарегистрированной службы агента ещё не принят.

Microsoft WMF 5.1 для Windows Server 2012 R2 скачан из Microsoft Download
Center, каталоги проверены Authenticode. SHA-256 пакета KB3191564 x64
`a8d788fa31b02a999cc676fb546fc782e86c2a0acd837976122a1891ceee42c0`.
Установка KB3191564 вернула 3010. После перезагрузки в 15:32:59 UTC+05:00
WinRM подтвердил PowerShell `5.1.14409.1005`, наличие KB3191564 и отсутствие
ожидающей перезагрузки CBS. Сервер, агент администрирования и веб-консоль
Kaspersky Security Center работают. Служба `AVP` была остановлена до
перезагрузки и после неё. SMB отвечает на TCP 445, KSC на TCP 13000.
Windows публикует 19 дисковых ресурсов. Оба входа Endpoint вернули HTTPS 200.

Повторная предварительная проверка подписанного Setup вернула 0. Windows
Installer зарегистрировал установку Endpoint Agent 3.2.193 со статусом 0
(событие 1033 в 15:37:07 UTC+05:00). Штатные этапы `finish` и
`verify-settled` прошли. Затем `native-continuation` завершился ошибкой,

`6772674d-0dfb-4aeb-9d77-198729c86fbd` из сохранённого подписанного Setup
вернуло 60 (`REPAIR_REQUIRED`). Удержание транзакции сохранено, MSI повторно

SHA-256 скрипта обновления 1.0.8 из помощника установки совпал с SHA-256
установленного файла `11e4793a2064726f956ce9eac12c50e04b785012cacb161e6fed154ef9447a66`.
Windows SDK SignTool подтвердил подпись и метку времени этого файла.
PowerShell 5.1 на ANTARES подтвердил подпись и издателя, но вернул пустой

Службы Endpoint Agent и его обновления остановлены. Console по имени
ANTARES и IP 192.168.100.4 карточку не нашла. Локальный замер после установки
MSI показал C: 32,6% и E: 84,4% занято. Телеметрия в Console не поступила.

Прошли 91 тест Python и 124 теста Console, четыре теста Python пропущены.
Проверка контрактов и production-сборка Console прошли.

## Проверка метки времени через WinTrust

SignTool на самом ANTARES подтвердил издателя, метку DigiCert и её цепочку.
В обеих разрядностях PowerShell 5.1 обычный вызов `Get-AuthenticodeSignature`
возвращает `Valid` с пустым полем метки времени. Проверка двух внутренних
ветвей PowerShell показала, что поле пустое в `GetSignatureFromCatalog`, а
`GetSignatureFromWinVerifyTrust` возвращает сертификат для того же файла.
Нативный WinTrust подтвердил одну действительную контрподпись DigiCert.

В исходном коде помощника Setup добавлена проверка контрподписи средствами
WinTrust, когда PowerShell подтвердил подпись и ожидаемого издателя, но не
вернул сертификат метки времени. Подписанная диагностика с этим кодом
приняла исходный файл на ANTARES, отклонила изменённый и неподписанный
файлы и не приняла исходный файл при проверке с другим издателем. Тестовая
регистрация подписанного каталога для отдельного диагностического скрипта
не изменила результат PowerShell. Каталог и диагностические файлы удалены.

Исходный подписанный Setup 3.2.193 содержит прежнюю проверку. Его
сохранённая транзакция была привязана к хешу исходного помощника. До
восстановления службы Endpoint были остановлены, карточка ANTARES
отсутствовала в Console. Локально работали KSC и SMB, C: 32,5%, E: 84,4%.
