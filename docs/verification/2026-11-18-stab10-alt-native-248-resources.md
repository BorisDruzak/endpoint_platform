# STAB-10. Нехватка места и inode на ALT 11.4 с 3.2.248

Проверка выполнена на VM191, полном клоне
`inventory-alt114-p11-rpm-ready` VM132. Клиент использовал подписанную
пару RPM 3.2.248-alt6 из исходника
`7bd7086a4650c9c9abd2218b2b9bbd0633235302`. Для него отдельно
создали одноразовое разрешение в лабораторном Gateway на закрытом
мосту. До проверки зарегистрированы одна карточка, одно событие
установки с ACK №1 и WSS 3.2.248.

Во всех сценариях использовали один штатный архив Core OTA 3.2.206,
21 763 666 байт, SHA-256
`ebb77e1a8a2adb9730669e1ef16ccbfe6a781fbc0a2747b6fa0fd209d40ad504`
и сохранённую подпись авторизации издателя. Локальные запросы
обработал установленный привилегированный bridge. Четыре прогона
прошли с ограничениями tmpfs в отдельных пространствах монтирования.

| Сценарий | Блоки по 4 КиБ, свободно | Свободные inode |
| --- | ---: | ---: |
| Место для распаковки | 16 384 | 4 095 |
| Inode для распаковки | 65 536 | 15 |
| Место для локальной очереди | 6 973 | 4 092 |
| Inode для локальной очереди | 27 453 | 12 |

Во всех четырёх случаях preflight вернул 1 и `alt_update_no_space`.
Пятый прогон повторил нехватку места на staging через штатный
`endpoint-agent-update.path` и установленную службу без drop-in.
Журнал systemd подтвердил `status=1/FAILURE` и тот же код preflight.
В каждом прогоне отмечен ровно один локальный отказ, PID и InvocationID
Core совпали. Селектор, нативный журнал и четыре приватных файла
сохранили SHA-256, inode, владельцев и режимы. Маркер остановки Core
и каталог целевой версии отсутствовали.

После размонтирования штатный watcher принял новый запрос
`cd7e1c3e-7062-4dbc-9338-7b221c2bf728`, выбрал 3.2.206 и записал
один успешный результат. Gateway принял WSS
`674fc937-bffb-4054-8b6b-a53d5355256a` на той же карточке.
Штатный откат восстановил селектор 3.2.248, чистый `rpm -V`
и WSS `22b5d163-4f82-4b34-b3c1-79f6f0211ffb`. Исходный ACK №1
и хэши четырёх приватных файлов сохранились.

Проверено отсутствие тестовых монтирований после прогона. VM191,
её диск, временные API, worker, БД, IP и рабочие каталоги удалены.
Исходные сервисы VM142 активны. Материалы находятся в
`C:/endpoint-platform-wix-build/stab10-alt-native-248-20261118`.
Хэши основных квитанций приведены в `evidence.sha256`.
