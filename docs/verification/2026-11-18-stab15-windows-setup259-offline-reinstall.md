# STAB-15. Офлайн-удаление и переустановка Windows Setup 3.2.259

Испытание проведено 18 ноября 2026 года на изолированном Windows 10 Enterprise Evaluation amd64 build 19045. VM222 получила исходную карточку от остановленного лабораторного VM206. На выделенном Gateway VM223 была одна карточка. Перед удалением точный Setup .259 уже прошёл штатный ремонт и Restart с ACK 5. Во время удаления, переустановки и первого Restart адаптер VM222 оставался link-down. Обе операции выполнялись в контексте LocalSystem без интерактивного входа.

| --- | --- |
| Подлинность | Source 85f78df48ca891956e614cd6afd63eb03c22dea2. Подписанные Setup и MSI имеют действительную подпись с меткой времени. Отпечаток сертификата издателя 4D4C23389F5FF77BC4EB32044761019EAE8FB776. Кэшированные Setup, MSI, манифест и штатная обёртка совпали по SHA-256 с проверенными входами подписанного Setup. Обёртка Install-EndpointAgentCanary.ps1 сама имеет статус NotSigned. |

Четыре защищённых файла совпали на пяти этапах. Агрегат e63aea64c8e3f01bb20088d1808202ef7f22132921a651fbe48e6f9787b2412c вычислен по хешам содержимого, длинам, NTFS file ID и SDDL. После холодного запуска часы VM222 опережали хост на 13 часов. Перед удалением штатный QGA sync исправил время, проверенный остаток был менее 0,01 с.

Локальный сценарий завершил запуск обёртки удаления, затем допустил ошибку при формировании JSON. Числовой код внешнего процесса удаления не извлечён. Нативный exit 0 и удаление подтверждаются сохранённым защищённым событием и проверкой состояния. На заключительной сверке в 17:56:30 UTC регистрация Support отсутствовала и на госте, и у провайдера. Была запланирована отдельная задача SupportReinstall для события 7. Проверка независимого SSH остаётся открытой.

Квитанции находятся в C:/endpoint-platform-wix-build/stab15-win259-remove-reinstall. Ключевые исходы сопоставлены скриптом verify-receipts.py, входы перечислены в receipts.sha256. На рабочей станции сохранена защищённая копия контрольной БД после ACK 7, 305 751 байт, SHA-256 aba02a7832031755a8edd5e65099851bfe4623d68dc2f65089794c2a11f70b0e. Список объектов и штатное декодирование PostgreSQL custom dump проверены.

VM222 выключена, link-down, сохранён снимок setup259-reinstall-ack7-offline с точным установочным носителем. VM223 и исходный контрольный снимок ACK 5 сохранены для следующего отдельного испытания Windows.
