## STAB-09. Таймаут и повторная загрузка архива на Windows

На Windows из проверенного подписанного Setup 3.2.253 извлекли штатный ZIP размером 22 775 610 байт и загрузили модули скачивания из вложенного Core в тестовый процесс CPython 3.12.16 с aiohttp 3.13.3. Хеш исполняемого файла совпал с содержимым staging MSI и с Core установленной лабораторной версии. Проверка использовала HTTPS на loopback с валидацией сертификата и два вызова загрузчика.

При первом вызове сервер передал 65 536 байт и приостановил поток. Через 15,031 с загрузчик вернул ошибку таймаута и удалил временный файл. При втором вызове тест выдавал данные порциями с интервалом 5,75 с. Загрузчик получил и проверил весь архив за 23,094 с при общем тайм-ауте HTTP-сессии 20 с. SHA-256 полученного ZIP — `b05150dccd4221597d8ded53d043cb2c8495417e1e16904523dc2cce3997f3c6`. Временные файлы после каждого вызова отсутствовали. Повтор инициировал тест. Автоматический повтор установленного агента относится к отдельной [проверке перехода 3.2.237 → 3.2.238](2026-11-14-agent-release-qualification-matrix.md#лабораторный-windows-core-32238).
