# STAB-15. Windows 11 LTSC, офлайн-проверка 3.2.205 → 3.2.264

На VM250 проверили подписанный Setup 3.2.264 на независимом клоне снимка `130/applied-205-before-194`. Перед первым запуском отключили сеть. Windows 11 Enterprise LTSC 26100.9457 подтвердила отсутствие сетевого адаптера и маршрутов по умолчанию. Системная дата соответствовала 19 ноября 2026 года, состояние лицензии было 5, оставалось 0 минут льготного периода.

| До обновления | Исходные MSI и Core .205 совпали с известными хешами, служба работала. У EXE и MSI .264 проверены подписи, метки времени и совпадение SHA-256 с карточкой кандидата. |
| Предварительная проверка | Штатный Setup вернул 0 и `READY_FOR_SETUP_UPGRADE`. |

| Откат | После ожидания подтверждения Gateway Setup вернул 67 и `CANDIDATE_ROLLED_BACK`. Общее время запуска составило 623,7 с. В той же загрузке система восстановила MSI и Core .205. Служба работала, все процессы Setup завершились. |

Тест подтвердил локальный запуск .264 и автоматический возврат к .205 без сети. Приёмка Windows 11 сервером с подтверждённым событием установки и свежей сессией остаётся открытой. Для сравнения, [сетевое обновление Windows 10](2026-11-19-stab15-windows-primary205-to-264.md) на той же целевой версии завершилось применением.

После проверки удалены VM250, её диск и носитель с кандидатом. Исходная VM130 и её снимок сохранились. Загрузка нового образа Evaluation была остановлена, неполный файл удалён. Использовалась уже установленная ОС.

Проверены все 15 файлов индекса по SHA-256. Хеш индекса `88191cc7b9d0a5a6d4eace918e7d9992c90f53e1fc03e669f24627be52a75ae2`. ## Предусловия сетевого теста без повторной регистрации

В исходной VM130 сохранены staging origin и доверенный CA. SHA-256 установленного MSI .205 совпал с записями staging и production. Обёртки Setup .205 для этих каналов различаются. При обновлении уже зарегистрированного устройства служба и отправитель событий установки читают сохранённый origin. С операторской станции staging Gateway подтвердил имя и цепочку TLS и вернул HTTP 200 для проверки здоровья.

Для сетевого прогона требуется проверить в staging действующую карточку VM130, её последнюю подтверждённую последовательность и точную запись MSI .264. Контрольный пример в локальном журнале имеет последовательность 4. Доступные локальные дампы VM205 и VM226 относятся к другим устройствам. Штатный тест на самой VM130 изменит её версию и историю общей staging-карточки. Перед запуском также требуется сверить путь из гостя: у VM130 выключен виртуальный линк на одном адаптере, но внутри Windows видны два интерфейса и маршрут по умолчанию.
