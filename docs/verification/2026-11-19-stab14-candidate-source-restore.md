## Windows .262 и ALT .261

Исходники обоих кандидатов восстановили из отдельных Git bundle в
новые пустые bare-репозитории без alternates и shallow history.
`git bundle verify`, `git fsck --full --strict` и
`git fsck --connectivity-only` прошли для обоих. Дерево и все
упорядоченные связи предков совпали с исходными checkout.

| Кандидат | Commit | Tree | Коммитов в ancestry |
| --- | --- | --- | ---: |
| Windows 3.2.262 | `8e9976fecf9cfa9ae7e88f2d820df0e93aedaf0b` | `1a48aa677167d2b64e750deb246fd36802d59587` | 2 156 |
| ALT 3.2.261 | `788fe236bba1685526c270cc0febc11c9866697f` | `3593157e6fb4bf689789e1cf7811f0fe5551d7dc` | 2 147 |

Windows checkout использует alternates. Созданный полный bundle включает
только объявленную ссылку точной ветки кандидата и достижимые Git-объекты.
Он сохранён по пути
`C:/endpoint-platform-wix-build/stab14-candidate-source-restore/restricted/windows-3.2.262.bundle`
с ACL оператора и SYSTEM. Размер 8 531 746 байт, SHA-256
`511b6af85d6cc84c5e4268d4d6cc80f65334adba270ffe85e17994a96cc361fa`.

Существующий ALT bundle по пути
`C:/endpoint-platform-wix-build/stab15-alt-native-261/full-linux-gate/source.bundle`
содержит одну ссылку HEAD на точный исходник. Размер 8 473 141 байт,
SHA-256 `b5a47ea0785730837e4aefa1166921a46a445a7a353d20a987e51e703a9d8b1e`.

При исходных настройках интеграционный архив отличался окончаниями
строк. Для сравнения архивов использовали одинаковые параметры Git
`core.autocrlf=false`, `core.eol=lf` и `tar.umask=0002`, переданные
на один вызов. При них архивы из исходного, восстановленного и
интеграционного репозиториев побайтно совпали:

- Windows — `da6ab208814300f7f9596b514d03388c6d8279b2cbe0828e6fbd4ec3b3df0f57`.
- ALT — `70c14a5705cc5caf00cd898cf00d9075feafcc2bb466655f94cee1eb2f898d25`.

В integration доступны только две добавленные ссылки
`refs/verified-releases/windows/3.2.262` и
`refs/verified-releases/alt/3.2.261`. HEAD, ветка и прочие refs не
изменились. Ничего не отправляли во внешние репозитории.
Восстановление касается Git-исходников. Незакоммиченные материалы
подписания не входили в bundle. Восстановление внешних ключей остаётся
отдельной проверкой.
