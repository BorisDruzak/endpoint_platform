# STAB-15 — отказ repair .261 при пустом пакетном unit Core

На одноразовом ALT Workstation K 11.4 VM241 штатно установили исходную подписанную пару .261 из `788fe236bba1685526c270cc0febc11c9866697f`. До дефекта обе проверки `rpm -V` вернули 0, единственная лабораторная карточка имела ACK 1 и WSS .261. Для воспроизведения состояния VM221 обнулили только обычный пакетный файл `/usr/lib/systemd/system/endpoint-agent.service` и штатно перезагрузили клон. Маски, ссылки, override и настройки systemd не создавали. После загрузки у systemd были `LoadState=masked`, `NeedDaemonReload=no`, штатный FragmentPath и PID 0. Проверка RPM показывала только одно отличие, в этом unit.

Один запуск подписанного Setup `repair` с исходными RPM вернул 21 и общую фразу о незавершённой операции. Конкретного `safe_code` вывод не содержит. В exec-трассе первый и единственный вызов systemd был чтением свойств Core. Из 21 вызова инструмента RPM ни один не запускал системную транзакцию. Операция `613c6d67-0d76-4e8c-841f-4b203024514a` осталась `preparing` с пустым native exit. Обе NEVRA, защищённые файлы, селектор, прежний runtime-ready и ACK 1 сохранены. Gateway не получил новую установочную запись. Предварительный сборщик один раз остановился до запуска Setup из-за опечатки, что подтверждено отсутствием exec-трассы.

На точном исходнике [`installation_coordinator.py`](../../pc_agent/platform/linux/installation_coordinator.py) проверка установленной пары при входе в `repair` передаёт `verify_files=False`. На этапе `prepare` проверка конфигурации для штатного пути unit требует `LoadState=loaded`. Зафиксированное состояние соответствует ветке `foreign_native_unit_preserved`, это вывод из исходника и трассы. Данный прогон показывает, что штатный `repair` не восстанавливает повреждение, при котором systemd считает пакетный unit маскированным. Восстановление других классов повреждённых файлов в этом прогоне не проверялось.

Клон, диск, выделенная БД, процессы и адрес Gateway и временные каталоги удалены. [Архив 26 квитанций](C:/endpoint-platform-wix-build/stab15-alt-native-261/repair-masked-unit/repair-refusal.zip), SHA-256 `1d99474553917bc13d840484fd25e9b6f3c29022d25bee66a0b1bd637edb2815`. Проверены CRC, внутренний индекс SHA-256 и автономный `verify.py`.
