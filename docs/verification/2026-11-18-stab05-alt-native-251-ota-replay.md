# STAB-05. Повтор одного подписанного OTA-назначения на ALT 3.2.251

На ALT Workstation K 11.4 в закрытой сети одна утверждённая карточка получила обычное назначение Gateway 3.2.249 → 3.2.251. OTA-архив Linux 3.2.251 размером 21 852 228 байт собран штатным инструментом из байтов подписанного Core RPM. Внутренний manifest архива байт-в-байт совпал с manifest в RPM. SHA-256 архива `2409331fd9bf489157c9fa34e388095457a8d2915646e6100a4a37917b9c8829`, исходник `10a0a1c33bef241aaee0937b243b7954b67c6525`. Для лаборатории штатный издатель `BC24B8EE43DBB05A748E11A4343B5DA748370631` подписал локальную авторизацию этого точного архива. Gateway принял `applied/post_restart_handshake_confirmed`, а исполняемый файл и manifest запущенной 3.2.251 совпали с файлами подписанного RPM.

- После завершения исходного назначения штатный API Gateway назначил той же карточке rollback к историческому подписанному 3.2.206. Операция `a3ff2d8f-ef56-43d3-ac51-8c50da17d19c` получила scheduled ACK. Ограничение в 8 МиБ на временной ФС привело к `alt_update_no_space` до смены активного Core. История сохранила один отказ.
- Ограничение сняли в 06:15 UTC. В 06:17:18 Gateway снова выдал ту же операцию после естественного опроса. Лабораторный HTTP-обработчик удержал её terminal POST до записи, поэтому сервер всё ещё показывал `scheduled`, без terminal report. Клиент сохранил один отказ, прежний PID Core 3.2.251 и одну недоставленную запись `failed/launcher_apply_failed`. После снятия ограничения не было второго скачивания, запуска установщика или новой pending-записи. В трассе ровно один GET архива 3.2.206.
- После снятия HTTP-ограничения в 06:22:18 естественный опрос доставил тот же report key `5bec5dde5b204ef58a26864cdd2954ef`. Клиент получил HTTP 200 и записал доставку. У Gateway одна строка отчёта об отказе `5db16d95-c735-4da9-998b-a5c9465ca6ac`, прежняя карточка и свежий WSS 3.2.251. Отдельный случай потери ответа уже после записи на сервере подтверждён на [Core 3.2.248](2026-11-18-stab05-alt-native-248-report-ack.md).

Временное монтирование снято. Удалены VM196, её диск, отдельные процессы и БД Gateway, дополнительный адрес и временные каталоги. Исходная VM132 осталась выключенной, три исходные службы VM142 активны. Подписанные материалы и квитанции сохранены. SHA-256 манифеста квитанций `e0c17258e98d9e5b8139235ab5e7a62e298eff17e31cf03efef427159ef8d21f`.

Каталог квитанций — `C:/endpoint-platform-wix-build/stab05-alt-native-251-ota-replay`. Файлы `held-artifact-wire.jsonl`, `recommendation-wire.jsonl` и `final-provider.json` связывают скачивание, повторную выдачу и итоговую запись Gateway.
