# Сетевой переход Windows 10 с 3.2.205 на 3.2.276

25 ноября 2026 подписанный Full Setup 3.2.276 прошёл точечное сетевое
обновление с 3.2.205 на Windows 10 Enterprise Evaluation x64 build 19045.
Обычная лабораторная Console приняла native exit `0`, ACK2 и новый WSS
на исходной карточке. Подтверждены 182,29 секунды стабильного наблюдения и
свежий образец UserSensor из прежнего интерактивного сеанса. Console выдала
квалификацию для исходной Foundation 3.2.205 в БД стенда.

## Результат

- До назначения подтверждены Foundation/Core 3.2.205, готовый Observer 1.0.11
  и исходный ACK1. Политика активности подтверждена до открытия сеанса.
  Для сеанса использовалась временная обычная учётная запись на клоне.
  Параметры разового входа удалены после загрузки. Исходные Tray и UserSensor
  запущены в этом сеансе из точных байтов 3.2.205 при помощи временных задач
  с интерактивным токеном без повышения прав. Gateway получил реальный
  образец UserSensor до назначения.
- Одно назначение создано в 13:21:32 UTC. Серверный интервал между стадиями
  `downloading` и `verified` составил 24,86 с. В 13:30:22 UTC назначение
  достигло `applied / setup_post_restart_confirmed`, через 8 мин 50 с после
  назначения. Это длительности одного прогона на данной конфигурации.
- Итог Setup `UPDATED / SERVICE / SERVICE_RUNNING / 0`. Нативный журнал
  достиг `accepted`, sequence 5. Один установленный MSI и запущенный Core
  совпали с точными хэшами 3.2.276. ID, ACL и содержимое четырёх частных файлов
  совпали до и после. Обновление прошло в одной загрузке Windows.
- Подтверждены два последовательных доставленных нативных события,
  одна карточка и одна активная учётная запись устройства. Новая WSS-сессия
  открылась после старта назначения. Через неё прошёл один `health_v1` с
  успешными доставкой и результатом. В том же сеансе Windows восстановлен
  один UserSensor из подписанного MSI 3.2.276 и получен его свежий образец.
- Observer 1.0.13 сообщил готовность. Запрос квалификации с текущими ID
  релиза и назначения вернул HTTP `200`. Первый запрос со старыми ID из
  шаблона стенда вернул `409`. Повтор выполнялся только для квалификации.
  В БД стенда было одно назначение, ноль строк fleet policy и ноль кампаний
  регистрации для цели 3.2.276.
