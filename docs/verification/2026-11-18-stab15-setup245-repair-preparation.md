# Подготовка стенда для ремонта Setup 3.2.245

18 ноября проверена доступность лицензированной лабораторной VM с
установленной и принятой 3.2.245. Точный подписанный EXE имеет SHA-256
`06f6f93ea766e083f328606745497a397cbd6cfd39f49fb204670489ce0b0d5f`.
Стенд предыдущего успешного перехода VM174 и его БД удалены после
приёмки. В `pbs`, `local` и `zfs-vm-storage` на pve1 не найдено
резервных копий VM169–174.

| Копия | Установленное состояние и лицензия |
| --- | --- |
| VM176 из `147/stab15-win147-229-clean` | Windows 10 EnterpriseEval `19045.2006`, `LicenseStatus=5`, 0 дней. Setup не запускался. |
| VM177 из `130/applied-205-before-194` | Windows 11 Enterprise LTSC `26100.9457`, `LicenseStatus=5`, 0 минут. MSI и Core 3.2.205, историческая привязка к staging, четыре локальных файла идентичности. Setup не запускался. |
| VM175, полная временная копия остановленной VM143 | Windows 10 EnterpriseEval `19045.6456`, `LicenseStatus=1`, 120 476 минут. MSI и Core 3.2.237, историческая привязка к staging и четыре локальных файла идентичности. |

Все три Windows-копии проверены через QGA без сетевых адаптеров.
Отдельный лабораторный Gateway на `44d96b5cce41` запустился с пустой
БД, мигрированной до 0056. Windows к нему не подключалась.

На VM175 зарегистрированный MSI и SHA-256 `LocalPackage` совпали
с точным подписанным MSI 3.2.237. Подписи EXE и MSI прошли проверку.
Зарегистрированная строка удаления указывала на `MsiExec.exe`
и точный ProductCode этого MSI. Запуск стандартного `msiexec /x`
для этого ProductCode завершился за 2,282 с, код 1603.
Событие `MsiInstaller` 11722 зафиксировало `InstallerOwnerPreflight`
и 1722. После отказа сохранились регистрация MSI, Program Files,
четыре службы и работающий Core. Байты и ACL четырёх файлов
идентичности совпали. Интерфейс Windows для удаления отдельно не
проходили.

Защищённый путь оператора в этой ревизии использует
`Install-EndpointAgentCanary.ps1 -Operation Uninstall`. Объявление
аргументов Setup и документация в точном исходнике 3.2.237
отдельного подписанного режима удаления EXE не описывают.
Действующая политика PowerShell в VM175 — `Restricted`. Скрипт
удаления не запускался. После отказа MSI очистка ProgramData
не выполнялась. Отдельная регистрация, ремонт той же 3.2.245,
офлайн-переустановка и проверка SCM именно на 3.2.245 остаются
незавершёнными. Требуется подготовленный лицензированный стенд с
принятой 3.2.245 или доступный штатный путь удаления старого агента
и выпуска нового лабораторного удостоверения.

VM175, VM176 и VM177 штатно выключены и удалены со своими дисками.
Оба ISO, отдельные службы API, worker и PostgreSQL и временные
каталоги удалены. Исходные VM143, VM147 и снимок VM130 сохранены.
Историческое удостоверение не подключалось к сети. Квитанции
