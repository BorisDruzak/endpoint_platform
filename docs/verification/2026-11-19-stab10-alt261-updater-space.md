# STAB-10. Нехватка места для OTA на подписанной ALT 3.2.261

На одноразовой ALT Workstation K 11.4 x86_64 VM221 установили подписанную пару из `788fe236bba1685526c270cc0febc11c9866697f`. SHA-256 комплекта `0299cdd07bc6e27b2b3503db8885c587737101c8aa6c6dce91de2614343642f1`, Core RPM `018ab4d1c3abc4619c4d59cfa74da1e9655971a1876a247ca7393cde8a05f1cd`, UserSensor RPM `f02933902e73d103af6d35d575b8502af1fa2937ffd643e33244ed6a5c3b3510`. Выделенный TLS Gateway подтвердил одну лабораторную карточку, ACK 1 и WSS 3.2.261.

Штатному watcher передали один локальный запрос на сохранённый Core OTA 3.2.206 с исходной подписью авторизации. Архив имел 21 763 666 байт и SHA-256 `ebb77e1a8a2adb9730669e1ef16ccbfe6a781fbc0a2747b6fa0fd209d40ad504`. Единственное ограничение установили отдельным tmpfs на каталоге распаковки `/opt/endpoint-agent/versions/_alt_update_staging`. На нём было 16 384 свободных блока по 4096 байт и 4095 свободных inode. Корневой том гостя и хранилище гипервизора не заполняли.

Установленный `endpoint-agent-update.path` запустил штатную службу без override. Preflight вернул `alt_update_no_space`, systemd записал `status=1/FAILURE`. В истории ровно один отказ для операции `e497a112-11e7-4b92-83d0-acfd421f79a9`. Маркер остановки и каталог целевой версии не появились. Core сохранил PID 3041, InvocationID и монотонную метку входа в active, WSS осталась на прежней карточке. Селектор, нативный журнал, конфигурация, CA и два файла идентичности сохранили хеши, inode, владельцев, режимы и ACL. Оба установленных RPM прошли `rpm -V`. Проверка ограничена одним отказом по месту через локальный watcher. Штатную серверную выдачу, нехватку inode и успешное применение после снятия лимита здесь не повторяли.

Tmpfs размонтирован. ВМ, диск, выделенные Gateway и БД, дополнительный IP и временные каталоги удалены. Квитанции находятся в `C:/endpoint-platform-wix-build/stab15-alt-native-261/updater-space`. SHA-256 `receipts.sha256` — `c5414f035f8a2364ca1acb7b1a89b22266d4b0f3660c07faa6e919ed405b8890`.

```powershell
python -B C:/endpoint-platform-wix-build/stab15-alt-native-261/updater-space/verify-space.py
```

## Отдельная проверка нехватки inode

На новом одноразовом ALT Workstation K 11.4 той же подписанной паре .261 передали один локальный запрос на тот же подписанный Core OTA .206. В отдельном tmpfs каталога распаковки оставили 536 870 912 свободных байт и один свободный inode. Проверенный архив требовал 116 781 948 байт и 137 inode с учётом резерва установщика.

Штатный watcher зафиксировал ровно один отказ `alt_update_no_space` для операции `e5cd940e-b517-4493-a0af-db514576a39f` до остановки Core. PID 3019, systemd InvocationID и время активации не изменились. Gateway сохранил ту же WSS и единственное событие установки с ACK 1. Селектор и защищённые файлы остались прежними, `rpm -V` прошёл для обоих пакетов. ВМ, диск, выделенные Gateway и БД, дополнительный IP и временные каталоги удалены.

Квитанции в `C:/endpoint-platform-wix-build/stab15-alt-native-261/updater-inodes`. SHA-256 `receipts.sha256` — `e8a54468adeff161a426efbd60cafb84e5a3f10f688e0fc590c58ad161122434`. Повторная проверка — `python -B verify-inodes.py` из этого каталога.
