## Результат исправления ALT Setup

Два теста воспроизвели частичный файл под итоговым именем при симуляции
`ENOSPC` после первых записанных байтов. После исправления для RPM и Setup
тесты подтвердили отсутствие итогового файла после ошибки и повторное
сохранение исходных байтов. Выборка из тестов нативного жизненного цикла,
параметров стенда, RPM и комплекта дала 143 успешных теста и 3 пропуска на
Windows.

На изолированной ALT Workstation K 11.4 проверены функции из коммитов
`88e0809a2cd6b7ccbbc646310426aebc6127c2f1` и
`3f1dc26ac0d50bab39dab4c9e04cb026f6086d54`. В приватном пространстве
монтирования tmpfs размером 64 КиБ вернула фактический `ENOSPC` при
копировании 192 КиБ. Исходный код оставил частичный конечный файл для обоих
входов. После исправления конечные пути отсутствовали. Повтор на tmpfs
размером 1 МиБ сохранил точные байты с правами 0400 для RPM и 0500 для
Setup. Проверку Setup завершили на границе передачи управления. RPM и
подписанный установщик в этой проверке не запускали.

Исправление находится в исходниках режима DEVELOP и потребует нового
отдельно квалифицированного комплекта. Квитанция .274 относится к её
исходным подписанным байтам.

Для исправления нужен маршрут ALT native Setup. RPM содержит привязку к
SHA-256 конкретного Setup, поэтому новый бинарь требует нового подписанного
комплекта с согласованной парой RPM. Изменения Windows CI относятся к
подготовке среды проверок. Для них отдельный Core или Full Setup не требуется.
