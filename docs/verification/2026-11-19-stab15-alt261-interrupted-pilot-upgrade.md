# STAB-15. Восстановление прерванного нативного обновления ALT .183 → .261

На одноразовой ALT Workstation K 11.4 x86_64 VM221 проверили подлинные подписанные комплекты `3.2.183-alt6` и `3.2.261-alt6`. Хеши архивов соответственно `c5b552afa4aa27e4df73af0ce68be4ecc88729f30baf3a70e6f9d4c8c709a3f3` и `0299cdd07bc6e27b2b3503db8885c587737101c8aa6c6dce91de2614343642f1`. Для .261 исходник `788fe236bba1685526c270cc0febc11c9866697f`, Core RPM `018ab4d1c3abc4619c4d59cfa74da1e9655971a1876a247ca7393cde8a05f1cd`, UserSensor RPM `f02933902e73d103af6d35d575b8502af1fa2937ffd643e33244ed6a5c3b3510`. Начальная .183 совпала с [проверенной парой пилота](2026-11-19-stab15-alt-native-183-to-261.md) и получила ACK 1 на выделенном TLS Gateway.

После снятия carrier запустили обычный `endpoint-agent-setup upgrade`. Наблюдатель подтвердил исходного координатора по PID, времени старта, boot ID и группе процесса. В журнале уже сохранялся native exit 0. После появления дочернего read-only `rpm -q` координатор прервали. В этот момент операция `fafa5fd2-c704-42d3-9370-19705682d764` оставалась в `invocation_possible`, sequence и ACK совпадали с 1, события 2 и маркера `runtime-ready` не было. После выключения и холодной загрузки при отключённом carrier тот же operation ID, сохранённый exit 0 и ожидающее состояние подтвердились. Оба установленных RPM .261 прошли `rpm -V`.

После возврата связи один штатный `reconcile` завершился кодом 0. Трасса содержит только шесть RPM-запросов `-q`/ `-V`, время установки обоих RPM совпало до и после. Gateway принял ровно одно новое установочное событие с исходным ID прерванной операции и правильной ссылкой на событие .183. Получен ACK 2, прежняя карточка восстановила WSS `cefd9e8d-a7cf-4c7b-8ec3-fbe6488504db` с Core .261. Селектор перешёл на .261, идентичность, CA, конфигурация и ACL сохранились. Core, watcher и Support вернулись в исходное активное состояние. Туннель Support не открывался. Более ранней квитанции прерывания до RPM на этой точной паре в архиве не найдено. Этот прогон относится к уже сохранённому RPM 0.

Удалены VM221, диск, выделенные Gateway и БД, дополнительный IP и временные каталоги. Квитанции в `C:/endpoint-platform-wix-build/stab15-alt-native-261/interrupted-pilot-upgrade`. SHA-256 `receipts.sha256` — `d56be6c097114449746b2f2fa9e245f3cb5476d80f0316b8dc2c518cca7cc28c`.
