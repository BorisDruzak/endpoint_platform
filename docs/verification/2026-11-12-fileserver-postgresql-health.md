# Серверные проверки FILESERVER и DIRPOST

12 ноября 2026 года production Console и API приняли профили
`file_server` и `postgresql` из ревизии
`e56731cee985af2ef881c9165d1a16db9361fae0`.

| Сервер | Версия | Отчёт принят, UTC | Результат |
| --- | --- | --- | --- |
| FILESERVER, 192.168.100.40 | Windows Core 3.2.196, Foundation 3.2.193 | 06:34:26 | Обе SMB-службы активны, TCP 445 отвечает, опубликованные дисковые ресурсы есть. C: занят на 29,8%, D: на 50,8%. |
| DIRPOST, 192.168.100.27 | Ubuntu DEB 3.2.196-1ubuntu1 | 06:30:10 | PostgreSQL 14 main активен и принимает подключения на 5432. Корневой том с данными занят на 19%, /boot на 10,9%. |

Оба отчёта открыты в Console в разделе «Контекст → Состояние → Серверные
проверки». PID SMB и PostgreSQL не изменились. PostgreSQL проверяется
через `pg_isready` без пароля. Проверка SMB передаёт статус наличия
дисковых ресурсов.

Пакет DIRPOST получен из подписанного APT `noble/main`. В каталоге
сохранены версии 3.2.191 и 3.2.192. SHA-256 подписанного индекса
`509933f92ed9d0c756ecd700e50ec49e6e014ed78837abfca75e9f4ba19b5f60`.
Индекс действует до 19 ноября 2026 года, 06:26:25 UTC.

На FILESERVER назначение Core запущено только для этого устройства.
Стадирование и доставка итоговой квитанции потребовали временно передать
существующей учётной записи LocalService владение каталогом `updates`.
Контроллер принял `applied` с кодом `post_restart_handshake_confirmed`
в 06:36:28 UTC. Исходный владелец SYSTEM, DACL и группа сверены после
восстановления. Файлы идентичности совпали побайтово по хешам.

Pytest завершился с 86 пройденными и 4 пропущенными тестами. В Console
прошли 124 теста, проверка TypeScript и production-сборка. Проверка
генерируемых контрактов прошла.
