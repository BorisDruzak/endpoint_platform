# Windows 11 LTSC. Обрыв во время перехода 3.2.205 → 3.2.276

25 ноября 2026 на изолированном клоне Windows 11 Enterprise LTSC
26100.9457 прервали подтверждённую активную транзакцию Full Setup
3.2.205 → 3.2.276. После холодной загрузки штатная задача восстановления
вернула 21. Нативный результат остался неопределённым, Core не восстановился.
Локальная служба Support запустилась с прежними бинарником и конфигурацией.

## Стенд и граница обрыва

VM481 создана из снимка `VM130/applied-205-before-194`. У клона перед
первой загрузкой удалены сетевые адаптеры и унаследованные параметры
пользовательской сети QEMU. Windows подтвердила 0 физических адаптеров и
0 маршрутов по умолчанию. Исходные MSI .205 и Core совпали с ожидаемыми
хэшами. Служба Core работала, исходный native ACK имел sequence 4.

Authenticode EXE и целевого MSI вернул `Valid`, у обоих присутствовали
метки времени. В 17:08:22.470 UTC наблюдались `switching` sequence 2,
сохранённая попытка с пустым native exit и дочерний `msi-executing`
точного MSI. Два MSI callback завершились, два процесса `msiexec`
оставались активны. Событию 1040 №2328 соответствовала открытая compound
транзакция. Через 1,37 с гипервизор получил запрос на паузу и подтвердил
отключение в 17:08:26.337 UTC.

## Холодная загрузка

- В 17:08:45.500 UTC началась новая загрузка. Штатная задача завершилась
  кодом 21. Через 191,92 с результат, ID операции и попытки совпадали.
  Хэши staged-записи, попытки, дочернего fence и указателя compound
  совпали с предаварийным срезом. Compound остался в
  `old-script-returned` без записи завершения.
- Windows Installer вернул `INSTALLSTATE_UNKNOWN` для обоих ProductCode.
  В каталоге отката Windows присутствовали 2 файла `.rbs` и 250 файлов
  `.rbf`, ключ Rollback Scripts сохранился. Это наблюдение состояния
  MSI и его данных восстановления. [Состояния продуктов Windows Installer](https://learn.microsoft.com/en-us/windows/win32/msi/productstate)
- Core не запустился, селектор остался нечитаемым. Байты, ACL и NTFS ID
  четырёх защищённых файлов совпали с исходным состоянием. Хэш журнала
  установки и последний подтверждённый ACK сохранились.
- `EndpointSupportAccess` запустился в режиме Auto с новым PID. Хэши
  подписанного бинарника и конфигурации совпали с исходными. Проверка
  охватывает локальный SCM, ВМ была без сети.

VM481 штатно выключена и сохранена со снимком
`msi-outcome-unconfirmed-276` для изучения незавершённого отката.
Гипервизор подтвердил сохранность исходного снимка и работающую VM130.
Повтор Setup и завершение отката остаются за пределами этого прогона.
Сетевой переход Windows 11 требует отдельной приёмки.
