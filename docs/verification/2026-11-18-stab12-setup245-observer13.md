# STAB-12. Таймаут preflight в подписанном Setup 3.2.245

Ранее под SYSTEM проверен подписанный Observer 1.0.12 из лабораторного
Setup 3.2.207. Он вернул preflight_observation_expired за 180,043 с.
SHA-256 этого файла
3ca1fec8de3abc5b1ed3e0a263f9dc280c30590e9471ec23fc2db187bd55f481
отличается от финального Observer 1.0.13
b504a8fb96ead642262494b53327c0c5a01da49a0285d9190c0364da72e399aa.
Последний совпадает по байтам с файлом из MSI staging .245 и
установленным Observer из лабораторной квитанции
fresh174-target-proof-qga.json. Текст Initialize-SetupPreflightProcess
вместе со встроенным C# и Read-SetupPreflight с фиксированным лимитом
180000 мс совпал после нормализации переводов строк. Отдельного
бинарного файла для этого helper в комплекте Observer нет.

18 ноября на изолированном клоне VM175 от VM143 без NIC выполнены
именно эти две функции из подписанного Observer 1.0.13. Windows 10
Enterprise Evaluation build 19045, LicenseStatus 1, PowerShell
5.1.19041.6456. Контекст SYSTEM подтверждён SID S-1-5-18.
На госте совпали SHA-256 Observer и EXE
06f6f93ea766e083f328606745497a397cbd6cfd39f49fb204670489ce0b0d5f.
Оба файла имели Authenticode Valid и метку времени.

Тестовая программа, принимающая штатные --preflight --quiet, запустила
дочерний процесс. В ходе проверки подтверждены родитель PID 3900 и
потомок PID 2712. Вызов вернул preflight_observation_expired за
180,0624392 с. Оба процесса завершились. Следующий вызов реального
подписанного Setup вернул endpoint_windows_fleet_preflight_v1 для
3.2.245. EndpointAgent остался Running с PID 2616. Контроллер вернул 0.

Здесь проверялся прямой вызов функций под SYSTEM. Установка, работа
запланированной задачи и повтор старых тестов переполнения stdout
не входили в этот прогон. В подготовительном запуске первая версия
тестовой программы отклонила непредусмотренный в ней --quiet.
После приведения аргументов тестовой программы к штатному вызову
получен таймаут, описанный выше. Подписанные файлы не изменялись.

## Граница объёма вывода в Observer из .268

19 ноября на Windows build 26100, PowerShell 5.1.26100.9711, из подписанного
Observer в staging пакета .268 вызвали функции предпроверки под текущей учётной
записью оператора. Проверены подпись, метка времени и тот же SHA-256
`b504a8fb96ead642262494b53327c0c5a01da49a0285d9190c0364da72e399aa`.
Один процесс PowerShell выполнил пять циклов по шесть вызовов с тестовым EXE.

| Вывод или поведение EXE | Результат во всех пяти циклах |
| --- | --- |
| Валидный JSON, ровно 32 768 байт | Штатная функция прочитала все 32 760 символов значения. |
| 32 769 байт в stdout или один байт в stderr | `preflight_unavailable` за 57–65 мс. |
| Зависший процесс или завершившийся родитель с живым потомком | При тестовом лимите helper 1 800 мс вернул `preflight_observation_expired` за 1 802–1 829 мс. |
| Обычный короткий JSON после каждой серии отказов | Следующий вызов успешно разобрал ответ. |

В каждом из 20 отказов проверили исчезновение обоих тестовых PID. Счётчик
дескрипторов всего PowerShell по завершении циклов составил 765, 770, 763, 770
и 775. Эти числа не позволяют приписать изменение конкретному владельцу.
