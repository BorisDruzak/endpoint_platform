## OpenVPN .30

- Заявка `6c5a9026-025e-4508-8338-121214f0d7c6` одобрена в веб-консоли. Первый bootstrap остановился до POST из-за завершающего перевода строки в локальном файле claim. Файл исправлен, успешно использован тот же claim. Одно использование зарегистрировало устройство `cce5f2bb-2313-4ddf-9355-c1df487e28f4`.
- Агент переключился с TCP 443 на 8443 и обратно на 443 без смены PID. Резервный Nginx зарегистрировал WSS HTTP 101. Тестовое правило ограничивало только UID агента и было удалено.
- Через подписанный APT выполнены откат до 3.2.191 и обновление обратно до 3.2.192. Production принял обе версии под тем же UUID. Оба файла идентичности сохранили байты, роль и резервный адрес сохранились.
- После перезагрузки в 03:27 изменился boot ID, идентичность побайтово совпала, агент снова открыл WSS на 443. Production принял свежий отчёт `health_v1` с ролью `openvpn`, двумя рабочими службами, HTTP 303 и UDP 1194. Корневой том OpenVPN отмечен как критический по порогу свободного места профиля.
