# STAB-15. Windows 10 и автоматическая доставка после офлайн-переустановки Setup 3.2.264

19 ноября 2026 года подписанный Setup 3.2.264 после офлайн-удаления и повторной установки вернул Core на прежней карточке. После обычной перезагрузки и возврата связи штатный таймер доставил оба исходных события в порядке очереди за 35,55 с. В интервале доставки ETW не зарегистрировал новых стартов `msiexec.exe`. Support остался недоступен с `support_dependency_recovery_required`.

## Исходная точка

VM262 — одноразовый полный клон выключенного VM206 `setup253-positive-offline`, Windows 10 Enterprise Evaluation x64 build 19045. SPP показал статус 5 и остаток 0 минут. Активацию не меняли. До первого подключения виртуальные часы синхронизировали с гипервизором и настроили соответствующий часовой пояс. VM263 — одноразовый клон лабораторного Gateway VM142, поднятый с собственной копией парной лабораторной БД ACK3, SHA-256 `443f1beb3f3909276ffb23d171b58672395d1cd0b84f70ed579540409be9e6b7`. Закрытый мост vmbr263 имел только два TAP и ноль глобальных адресов. В гостях отсутствовали маршруты по умолчанию. Штатное staging-имя прошло HTTPS-проверку с исходным CA до и после офлайн-фаз. ## Открытые результаты

- Код возврата процесса wrapper удаления не удалось зафиксировать. После завершения дочернего процесса внешний сборщик при формировании JSON попытался выполнить `true` вместо PowerShell-значения `$true`. Security 4689 не дал соответствующей квитанции. Статус Windows Installer 0 и нативное событие удаления подтверждены независимо. Удаление не повторяли. Исправленный сборщик сохранён вместе с использованной версией вне репозитория.
- EndpointSupportAccess отсутствовал до удаления и после возврата связи. После ACK6 диагностика обновилась и сохранила `support_dependency_recovery_required`. Задача завершила эту попытку с 75 и осталась Ready. На сервере Support credential отсутствует, автоматическое подключение не разрешено. Состояние системной зависимости отдельно не меняли. Результат закрывает автоматическую доставку lifecycle и функциональность Core в данном профиле.
