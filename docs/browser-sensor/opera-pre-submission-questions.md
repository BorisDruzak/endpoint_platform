# Opera pre-submission questions

These four unresolved questions require an authoritative Opera answer before implementation. Official documentation links checked on 2026-09-26 are recorded below; no answer is inferred where the documentation is ambiguous.

1. For a managed enterprise security extension, can organization/admin policy constitute sufficient authorization for collection of bounded domain/origin and security-event metadata, or is explicit per-user authorization required?

   Official documentation: [Acceptance Criteria — Monetization and data processing](https://help.opera.com/en/extensions/acceptance-criteria/#monetization-and-data-processing).

2. Can an Opera Add-ons extension whose Native Messaging companion is available only on Windows be accepted if on macOS/Linux it fails gracefully and clearly reports that the companion application is unavailable?

   Official documentation: [Acceptance Criteria](https://help.opera.com/en/extensions/acceptance-criteria/), [Publishing Guidelines — Test your extension](https://help.opera.com/en/extensions/publishing-guidelines/#test-your-extension), [Passing Messages in Extensions — Native Messaging](https://help.opera.com/en/extensions/message-passing/).

3. Is there a supported way to restrict an Opera Add-ons extension to Windows only?

   Official documentation: [Manifest Files — requirements](https://help.opera.com/en/extensions/manifest/#requirements), [Publishing Guidelines](https://help.opera.com/en/extensions/publishing-guidelines/), [Acceptance Criteria](https://help.opera.com/en/extensions/acceptance-criteria/).

4. For an enterprise extension whose only transport is Native Messaging to a local application, how should this be disclosed for acceptance review?

   Official documentation: [Acceptance Criteria — Extension Metadata and Monetization and data processing](https://help.opera.com/en/extensions/acceptance-criteria/), [Publishing Guidelines — Write a good description](https://help.opera.com/en/extensions/publishing-guidelines/#write-a-good-description), [Passing Messages in Extensions — Native Messaging](https://help.opera.com/en/extensions/message-passing/).
