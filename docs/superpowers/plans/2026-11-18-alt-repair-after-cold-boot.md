# ALT. План восстановления после прерывания ремонта

Цель — завершить исходный ремонт подписанной установленной пары после холодной загрузки в соответствии с [согласованным контрактом](../specs/2026-11-18-alt-repair-after-cold-boot-design.md).

- [x] В тестах координатора воспроизвести новую загрузку после сохранённого RPM 0. Три остановленные службы имеют новые монотонные метки, включённый ранее активный Support уже работает. Проверить результат, отсутствие повторных RPM и запроса на запуск Support. Отрицательные сценарии охватывают неопределённый исход, ту же загрузку, другое состояние службы, отключённый Support, PID или незавершённое задание.
- [x] В `pc_agent/platform/linux/installation_coordinator.py` сверить идентификатор загрузки и полные доказательства для всех служб до изменения состояния. Перенести допустимые наблюдения systemd на шкалу новой загрузки единственной записью в исходное свидетельство подготовки. При повторе в этой загрузке сравнивать уже зафиксированное состояние. Сохранить существующие проверки исходной операции, пакетов, post-скриптов, идентичности, конфигурации и конечных состояний.
- [x] Прогнать существующие тесты координатора и Linux native. Собрать подписанную пару из точной ревизии. На ALT 11.4 воспроизвести обе границы потери питания. Записать код Setup, исходную операцию, число RPM-транзакций, установочные события, состояние Support и контрольные суммы входов. Отразить результат в матрице приёмки.
