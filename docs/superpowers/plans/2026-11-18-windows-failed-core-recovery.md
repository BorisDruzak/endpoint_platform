# Восстановление Windows после аварийной остановки EndpointAgent

Оператор запускает подписанный Setup более новой версии на зарегистрированном компьютере с параметром `--recover-failed-core`. Приёмочный стенд для этого изменения — изолированная Windows с установленной 3.2.245. Применение на DESKTOP-9ST5HO2 требует отдельного решения.

## Допуск и результат

1. Установщик проверяет локальную интерактивную сессию администратора с повышенными правами, принадлежность исходного пакета, селектора и регистрации. Источник должен иметь корректные исходные данные для отката. Активная или неопределённая операция установки сохраняет владение.
2. SCM должен показывать автоматический запуск ожидаемого процесса от LocalService, состояние Stopped, PID 0, код Windows 1066 и ненулевой код службы. Проверка повторяется перед переключением. Ручная остановка с кодом 0, отключение запуска и смена состояния требуют завершить попытку до переключения.
3. Испытание использует существующую транзакцию MSI и обычную проверку работоспособности кандидата. Успех подтверждают новая аутентифицированная сессия на прежней карточке, исходная идентичность и завершённая нативная операция.
4. При отказе испытания возвращаются исходные проверенные MSI и селектор. Исходный Core должен остаться остановленным с восстановленным типом запуска. Код завершения нового Setup и сохранённая квитанция позволяют оператору отличить откат от успешного обновления. Неопределённый исход нативной операции требует штатной сверки владельца.

## Выполнение и приёмка

- В `setup_entry.py` ограничить новый режим зарегистрированным предшественником и более новой версией. Проверить отказ для чистой установки, той же версии, понижения и прерванной установки.
- В `Install-EndpointAgentCanary.ps1` привязать допуск к оператору и повторным наблюдениям SCM. Проверить неизменность правил обычной выкладки и откат по сохранённым исходным состояниям служб.
- Собрать отдельный неизменяемый лабораторный кандидат. Зафиксировать исходный коммит, хеши и подписи. Использовать оригинальные подписанные байты Observer 1.0.13.
- Снять доказательства успешного испытания и отдельно испытания без связи с Gateway во время проверки кандидата. Сверить код Setup, MSI, селектор, SCM, состояние сопутствующих служб, идентичность и число карточек. Для отрицательного испытания записать фактическое состояние до повторного подключения сети.
- Отдельно записать ограничения стенда и очистить временные ресурсы после сохранения квитанций.
