# ALT 3.2.266. План проверки записи ключей Support

Исполнение через субагентов и независимую проверку. Основа выпуска — подписанный исходный код .265. [Спецификация](../specs/2026-11-19-alt-support-key-durability-design.md)

## Ограничения и случаи для проверки

Регистрация в Gateway следует за проверкой и успешной синхронизацией обеих пар. Операция использует существующую блокировку хранилища, строгие проверки файлов и штатный HTTP-клиент. Для проверки требуются успешный первый запуск, повтор с сохранёнными парами, отказ записи отдельного файла, отказ записи каталога и повреждённая зарегистрированная пара. В стенде доступ Support выключен.
