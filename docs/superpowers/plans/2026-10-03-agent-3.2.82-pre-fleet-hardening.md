## Review Focus

1. Latest device instance has unknown foundation while an older row has a known value: fail closed; Task2.
2. Directory flush fails after atomic replace: selected candidate is never accepted by a failed write; reconciliation validates journal/proof; Task3/4.
3. Setup preflight passes immediately before OTA publication: mutual exclusion closes the race and Setup returns UPDATE_IN_PROGRESS without MSI mutation; Task6.
4. Newer selected runtime shares MSI ownership or conflicting same-version evidence: preserve validated newer core or reject conflict, never silently downgrade; Task7.
5. Space is exhausted while a journal or file is being flushed after a space precheck: old core survives and restart reconciles bounded safe state; Task5/11.
