# Windows Core OTA. Повтор после прерванного создания каталога

Пользователь выбрал автоматический повтор только при точном совпадении владельца и всех унаследованных прав. Основание — [наблюдения на подписанном Setup 3.2.255](../../verification/2026-11-18-stab03-windows-setup255.md). Контракт касается двух фиксированных каталогов подготовки Core OTA, `updates` и `updates/downloads`.

| Обнаруженное состояние | Действие службы |
| --- | --- |
| Каталог в штатном месте с канонической защищённой DACL и допустимым владельцем | Проверить только на чтение и продолжить исходную операцию. |
| Служба создала новый каталог или возобновила прерванное создание | Проверить владельца LocalService, всю цепочку пути, точную политику родителя и полный набор унаследованных ACE дочернего каталога. Довести этот каталог до штатной защищённой DACL, повторно проверить результат и продолжить. |
| Состояние не совпадает со штатным или не удаётся надёжно его прочитать | Остановиться до загрузки архива. Сохранить исходное назначение. |

У родителя `updates` и у родителя `downloads` разные штатные права службы updater. При проверке учитывать соответствующую политику, типы, маски и флаги наследования ACE. Повтор не требует смены владельца или выдачи службе дополнительных прав. Подготовка полученного архива, его подпись, блокировка загрузки и правила смены селектора продолжают действовать.

- [x] Закрепить регрессии для существующего каталога SYSTEM, полностью совпавшего унаследованного каталога LocalService и несовпадений. Охватить старые данные и повтор после прерванной подготовки каждого из двух каталогов.
- [x] Применить общий строгий валидатор в пути онлайн-обновления. Проверить, что при отклонении не выполняются изменение DACL, запрос архива и публикация pending.
- [x] На точном исходнике следующего кандидата выполнить release gate. На изолированной Windows получить штатный GET, проверить доставку и сохранение назначения, затем повторить удержание, обычную перезагрузку и откат.

Итоговый выпуск 3.2.259 прошёл полный release gate. На Windows 10 сохранены квитанции получения 3.2.260, удержания, применения после обычного Restart и автономного отката при отсутствии подтверждения. [Протокол](../../verification/2026-11-18-stab03-windows-setup259.md)
