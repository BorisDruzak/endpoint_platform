# ALT. Восстановление Core при ожидающей регистрации Support

На ALT Workstation K 11.4 после офлайн-удаления и переустановки пары 3.2.251 сервер принял оба события на прежней карточке. Затем конечная точка регистрации Support вернула HTTP 409. Setup оставил обе службы остановленными до ручного подтверждения администратора.

## Согласованное поведение

Для следующего кандидата выбран независимый запуск Core после подтверждённой переустановки. Прежний порядок ожидания обеих служб был вторым рассмотренным вариантом. Он сохранял единый момент готовности, но оставлял рабочую станцию без телеметрии.

Setup допускает этот сценарий только для точной установленной пары с завершённой нативной операцией, каноническими origin и CA, сохранённой идентичностью и подтверждённой сервером последовательностью удаления и последующей установки на той же карточке. Конфликт должен исходить от штатного запроса регистрации Linux Support. Ошибки TLS, аутентификации, доставки событий и прочие отказы сохраняют прежнее поведение.

Core получает возможность установить WSS и выполнить обычную команду проверки состояния. Support остаётся недоступным до штатного решения администратора. В журнале различимы готовность Core и ожидающая регистрация Support. По согласованному контракту Setup возвращает существующий код 21, пока регистрация Support ожидает оператора. После разрешения для одной карточки штатный reconcile завершает ту же операцию с кодом 0. Повторы, перезагрузка и остановка процесса между этими этапами сохраняют идентичность, принятое событие, исходную операцию и настройки доступа. Серверные правила регистрации и выдачи доступа сохраняются.

## Проверка

Тесты охватывают подтверждённую переустановку с конфликтом, первичную установку, неверный ACK, прочие ошибки HTTPS, повтор reconcile и восстановление после перезапуска. На отдельной ALT 11.4 проверяются точные подписанные RPM нового кандидата, одна карточка, рабочие WSS и health до решения администратора, недоступность Support и штатное завершение после решения. Приёмка требует квитанций ядра, Setup и Gateway для обеих стадий.
