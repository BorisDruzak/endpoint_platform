# Завершение работы Windows Setup Observer при удалении продукта

## Когда убирать задачу

Оператор выбрал все штатные окончательные удаления Windows, включая ПК до первой регистрации и зарегистрированные устройства. Основанием служит подтверждённое удаление MSI владельцем конкретной standalone-транзакции. На .264 после удаления до регистрации задача `EndpointSetupUpdater` осталась включённой и возвращала 20. [Нативная проверка](C:/endpoint-platform-wix-build/stab15-win10-clean-remove264-267/clean-offline-removal-264.md)

Setup проверяет принадлежность задачи продукту, закреплённое подписанное действие и состояние параллельных операций. Удаление считается завершённым, когда собственная задача отсутствует. При временном снятии MSI для обновления, ремонта или отката Observer продолжает обслуживать операцию. Отдельная задача доставки событий и журнал установки следуют своему действующему жизненному циклу.

## Результат для оператора

После подтверждённого MSI 0 штатный результат успешной очистки — Setup 0. Если задача занята или её принадлежность нельзя подтвердить, Setup сохраняет защищённую квитанцию и сообщает отдельный код 69 (`OBSERVER_CLEANUP_INCOMPLETE`). Нативный результат и исходное событие удаления сохраняются. Если также осталась служба Support, сохраняется действующий код 68 и в квитанции указываются оба результата. Посторонние задачи сохраняются.

Повтор очистки после устранения препятствия использует подтверждение исходного удаления. Он должен заново проверить отсутствие установленного продукта и конкурирующей установки, принадлежность задачи и актуальность операции. Повторная установка продукта прекращает действие прежнего основания для очистки. Повтор не запускает MSI и не создаёт второе событие удаления.

## Приёмка

На одноразовых Windows 10 проверить подписанный Setup до регистрации и после регистрации с отложенной доставкой. После обычной перезагрузки проверить отсутствие Observer, сохранение истории и доставку исходного события там, где есть удостоверение устройства. Локальными тестами проверить временное снятие MSI, отсутствие задачи, занятый Observer, несовпадающее действие, совместный остаток Support и Observer, повтор очистки и последующую переустановку. Для неполной очистки сверить отдельный код, неизменный MSI 0 и единственное событие удаления.
