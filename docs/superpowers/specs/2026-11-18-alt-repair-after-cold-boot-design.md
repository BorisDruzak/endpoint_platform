# ALT. Завершение ремонта после холодной загрузки

В ALT 11.4 после подтверждённого RPM 0 в операции ремонта 3.2.254 сменились монотонные метки systemd, а ранее включённая активная служба Support штатно запустилась при загрузке. Текущий reconcile вернул 21. Пользователь выбрал автоматическое завершение прежней операции при полном подтверждении исходных условий. Второй рассмотренный вариант сохранял 21 и требовал ручного разбора при каждой смене PID Support.

Для следующего подписанного кандидата reconcile проверяет доказанную смену загрузки и сохранённый успешный исход RPM именно этой операции, оба post-скрипта, точную пару установленных RPM, селектор, идентичность и конфигурацию всех служб. При сохранении этих условий разрешено восстановить прежнее штатное состояние служб. Уже штатно работающий Support, который был включён и активен до ремонта, остаётся в работе. Смена монотонных отметок между загрузками сама по себе не препятствует завершению. Результат — код 0 той же операции, единственная транзакция RPM и прежние события установки. Неизвестный исход RPM, недоказанная смена загрузки для этого исключения, чужая конфигурация или состояние служб сохраняют код 21. В пределах одной загрузки действуют прежние строгие проверки.

Проверка использует две ветви на ALT 11.4: выключение после сохранённого RPM 0 и выключение до появления нативного результата. Состояния сравниваются с неизменённой базой той же изолированной карточки.
